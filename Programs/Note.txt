A digit is simply an unsigned int and an integer is a vector of digits; here vector is the vector type of the standard template library. A declaration integer a(n) declares an integer with n-digits, a.size() returns the size of a and a[i] returns a reference to the i-th digiti of a. Digitis are numbered starting at zero. The global variable B stores the base. Functions fullAdder and digitMult implement the primitive operations on digits. We sometimes need to access digits beyond the size of an integer; the function getDigit(a, i) returns a[i] if i is a legal index for a and returns zero otherwise.
